# Responsible Use

This project is an analytical screening and prioritization tool for workshop electrical-safety review.

The score is not a certified electrical-safety determination. It should not be used to authorize energized work, declare an installation safe, diagnose electrical faults, or replace a qualified inspection.

Optional image review is deliberately limited to a generic local visual signal based on image statistics. It is not a trained hazard-recognition model and should never be interpreted as proof of an electrical defect.

Use qualified electrical professionals, applicable electrical codes, documented lockout/tagout procedures, incident protocols, and emergency services whenever required.
